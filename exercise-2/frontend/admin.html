Hạ Tầng AWS & DevOps Deployment

Trạng thái Multi-Container Docker, Nginx Reverse Proxy và cấu hình triển khai EC2

Kiến Trúc Multi-Container Docker

• Frontend Container (Nginx Alpine): Nhận traffic cổng 80 (HTTP) từ Internet, phục vụ Web tĩnh và chuyển hướng API.
• Backend Container (Node.js 18): Xử lý REST API trên cổng nội bộ 5000.
• Persistence Volume: Thư mục /app/data được gắn vào volume backend-data đảm bảo dữ liệu người dùng không bị mất khi reboot EC2.

docker compose up -d --build
Trạng Thái Máy Chủ Thời Gian Thực
• Môi trường: production
• Thời gian hoạt động (Uptime): 0s
• Bộ nhớ RAM tiêu thụ: 0 MB
• Phiên bản Node.js: -
• Cổng kết nối Nginx: 80 (HTTP chuẩn AWS)
Hướng Dẫn Nhanh Triển Khai Lên AWS EC2 Cho Giảng Viên / Kiểm Thử
  1. Tạo máy chủ EC2 (Ubuntu 22.04 / 24.04 hoặc Amazon Linux): Đảm bảo mở Security Group cho Inbound Port 80 (HTTP) và Port 22 (SSH).
  2. Cài đặt Docker trên EC2: Chạy lệnh sudo apt update && sudo apt install -y docker.io docker-compose-v2
  3. Clone dự án và khởi chạy:
    cd exercise-2 && docker compose up -d --build
  4. Truy cập ứng dụng kiểm thử:
    • Trang học tập: http://<EC2_PUBLIC_IP>/
    • Trang Quản trị Admin: http://<EC2_PUBLIC_IP>/admin (hoặc admin.html)
    • Tài khoản Admin kiểm tra: admin@nihongo.local / Mật khẩu: admin123
